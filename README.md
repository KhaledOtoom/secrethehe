# Valorant Duo Invitation

A mobile-first, single-page invitation site with a pastel opening screen, a playful escaping **NO** button, and a full-screen dancing-cat celebration for **YES**.

**Live site:** https://khaledotoom.github.io/secrethehe

## Project

- The complete site is in [`outputs/index.html`](outputs/index.html).
- It is plain HTML, CSS, and JavaScript. There is no package manager or build step.
- The illustration and celebration cats are inline SVG/CSS; there are no external image assets.
- Google Fonts are optional; system fallbacks are provided.

## GitHub Pages

The workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) publishes the `outputs/` directory to GitHub Pages on every push to `main`, and can also be run manually from Actions.
